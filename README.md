SpecStream provides a live web data engine for teams and AI agents, enabling deep search, extraction, and monitoring across the entire web. The platform offers searchable, extractable, and enrichable data with pay‑per‑match pricing, supporting use cases from sales leads to research and grant discovery. It includes APIs for search, extraction, deep search, signals, and sub‑processor monitoring, along with SDKs, CLI tools, and integrations for developers.

**Areas:** Data · AI · Search · Extraction · Monitoring

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for SpecStream: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
